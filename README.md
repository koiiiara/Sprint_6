
# Sprint_6

## Структура проекта

- **locators/**: Локаторы элементов
- **pages/**: Page Object файлы тестируемых страниц
- **tests/**: Файлы тестов
- **conftest.py**: Фикстуры для тестов
- **requirements.txt**: Список зависимостей для проекта
- **data.py**: Файл содержит константы и тестовые данные


## Список тестов

### Выпадающий список в разделе "Вопросы о важном":
- Проверка каждого вопроса и ответа на главной странице в разделе "Вопросы о важном" 

### Заказ самоката:
- Проверки процесса заказа самоката с 2мя разными точками входа и тестовыми данными

### Переход по логотипам в хедере:
- Проверка перехода с главной страницы на страницу Дзен по нажатию на логотип Яндекс
- Проверка перехода со страницы заказа самоката на главную страницу по нажатию на логотип "Самокат"

## Установка

Для установки необходимых зависимостей выполните следующие шаги:

1. Клонируйте репозиторий на локальную машину:
   ```bash
   git clone https://github.com/koiiiara/Sprint_6.git
   ```
   ```bash
   cd Sprint_6
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск тестов и генерация Allure отчета

Для запуска тестов и генерации отчета Allure выполните следующие команды:

1. Запуск тестов:
   ```bash
   pytest --alluredir=allure-results
   ```

2. Генерация и просмотр отчета Allure:
   ```bash
   allure serve allure-results
   ```

   Команда автоматически откроет отчет в браузере.
